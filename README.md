# BY YOUNG FINANCE
### Educação financeira acessível, prática e transformadora para jovens.

**Transformando a relação dos jovens com o dinheiro por meio da tecnologia e da educação.**

---

## Sobre o Projeto

A **BY YOUNG FINANCE** é uma plataforma digital de educação e gestão financeira pessoal, desenvolvida para ajudar jovens a conquistarem autonomia, organização e consciência sobre sua vida financeira.

Criada com o propósito de democratizar o acesso à educação financeira, a plataforma combina tecnologia, experiência do usuário e recursos interativos para tornar o controle do dinheiro mais simples, intuitivo e acessível.

Mais do que registrar movimentações financeiras, o projeto busca incentivar hábitos saudáveis de planejamento, consumo consciente e tomada de decisões financeiras.

## Objetivo

Contribuir para a formação de uma geração financeiramente consciente, oferecendo uma ferramenta gratuita que incentive o acompanhamento das receitas e despesas, o planejamento financeiro e o desenvolvimento da autonomia econômica.

## Funcionalidades

- **Gestão financeira:** cadastro e acompanhamento de receitas e despesas.
- **Dashboard interativo:** visualização da situação financeira por meio de gráficos e indicadores.
- **Relatórios financeiros:** acompanhamento das movimentações e dos hábitos de consumo.
- **Categorias personalizadas:** organização dos gastos conforme as necessidades do usuário.
- **Interface responsiva:** experiência adaptada para dispositivos móveis e desktops.
- **Educação financeira integrada:** conteúdos educativos conectados à realidade financeira dos jovens.
- **Acesso gratuito:** plataforma voltada à democratização do controle financeiro pessoal.

## Problemas que buscamos resolver

A falta de conhecimento e de ferramentas adequadas para administrar o próprio dinheiro pode dificultar o desenvolvimento da autonomia financeira entre os jovens.

A BY YOUNG FINANCE busca enfrentar desafios como:

- Falta de planejamento e organização financeira pessoal.
- Ausência do hábito de registrar receitas e despesas.
- Dificuldade em identificar gastos desnecessários.
- Consumo impulsivo e falta de controle do orçamento.
- Pouco acesso a ferramentas financeiras simples e intuitivas.
- Distanciamento entre educação financeira e situações práticas do cotidiano.

## Tecnologias e Arquitetura

O projeto possui uma estrutura dividida em duas aplicações:

- **Frontend:** responsável pela interface, navegação e experiência do usuário.
- **Backend:** responsável pelo processamento das informações e pela comunicação com o frontend.

## Como executar o projeto

### Pré-requisitos

Antes de começar, instale:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) ou outro editor de código.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd BY-YOUNG-FINANCE
```

### 2. Instale as dependências

No primeiro terminal, acesse a pasta frontend:

```bash
cd frontend
npm install
```

Em outro terminal, acesse a pasta backend:

```bash
cd backend
npm install
```

### 3. Execute as aplicações

**Frontend:**

```bash
npm run dev
```

**Backend:**

```bash
node app.js
```

### 4. Acesse a plataforma

Após iniciar os serviços, acesse o endereço local disponibilizado pelo terminal do frontend.
